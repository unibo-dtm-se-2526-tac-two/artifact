TAC2 COZY DESIGN KIT
Version 1.0

CONTENTS

tac2-logo.svg
  Horizontal Tac2 wordmark. Use on light backgrounds.

tac2-app-icon.svg
  Square application icon suitable for profile images, app tiles, and favicons.

mochi-mascot.svg
  Editable vector artwork of Mochi, the glasses-wearing Tac2 guide.

tac2-interface-icons.svg
  SVG symbol sprite containing the prototype's navigation and game-mode icons.
  Symbols: home, play, learn, trophy, profile, computer, friends, online,
  clock, spark, and download.

design-tokens.json
  Machine-readable palette, typography, radius, and shadow values.

USAGE

All SVG files can be dragged directly into Figma. Ungroup the imported vector
to edit individual shapes and colors.

The interface uses Fraunces for expressive headings and DM Sans for controls
and body copy. Both are available through Google Fonts.

Primary brand colors:
  Ink       #293B3A
  Cream     #FBF7EE
  Coral     #E97461
  Teal      #2F8A7F
  Gold      #E9AD4F
  Violet    #766AA5

Keep generous cream-colored space around the artwork. Use coral for player X,
teal for player O and primary actions, and gold for guidance or highlights.

The mascot and interface artwork were created for this Tac2 prototype.
